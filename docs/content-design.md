# 콘텐츠 규모와 뽑기 설계 (영웅·무기·장비)

작성: 2026-11-17. docs/design.md 3·4·5장을 "많이, 색만 바꾸지 않고" 기준으로 구체화한 것. 확정되면 design.md 에 반영한다.

## 0. 원칙

- 영웅, 무기, 장비 모두 뽑기로 얻는다. 던전 드랍은 보조(재료·골드·소환권).
- 색만 다른 영웅은 만들지 않는다. 영웅마다 체형·얼굴·머리·의상 조합·무기·스킬이 다르다. 색 변주는 같은 영웅의 "스킨" 으로만 쓴다.
- 장비는 캐릭터 몸에 보인다. 무기(손), 투구(머리), 갑옷(몸통), 망토, 방패가 실제로 바뀐다. 장신구·문장은 아이콘으로만.
- 모델은 오픈소스를 먼저 쓴다. 조합으로 수를 만들고, 최상위 등급만 따로 만든다.

### 2.2 영웅 한 명의 정의

```
영웅 = 종족·체형 (Base 6 + Races 12 = 18)
     × 얼굴·피부색
     × 헤어 (20)
     × 의상 조합 (머리 / 몸통 / 팔 / 다리 / 망토 파츠를 62개 중에서 고름, 색 3종)
     × 기본 무기군 (검·도끼·둔기·창·단검·활·지팡이·완드·격투 중 1~2)
     × 스킬 셋 (일반공격, 스킬 2, 필살기, 패시브) — 영웅 고유
     × 능력치 분포·원형(설계 의도)·진영
```

- 조합 수는 수천이지만 "영웅" 은 사람이 하나씩 고른 조합에 이름·스킬·성격을 붙인 것이다. 자동 생성으로 숫자만 늘리지 않는다.
- 같은 의상 파츠 조합을 두 영웅이 쓰지 않는다(머리·몸통·망토 3개 중 2개 이상 겹치면 안 됨).
- 등급이 높을수록 실루엣이 독특해야 한다.
  - 일반·고급: Base 체형 + 기본 의상
  - 희귀·영웅: 종족 변화(엘프·오크 등) + 조합 의상
  - 전설·신화: Races 의 큰 체형(드래곤·유인원), Bestiary 인간형 몬스터, 전용 무기
  - 불멸·초월: 전용 모델. Fantasy Races 중 드래곤 같은 특수형, 그래도 모자라면 AI 생성(Meshy·Tripo) → 휴머노이드 릭 리타깃. 한 등급에 몇 명만.

### 2.3 지금 영웅(KayKit)과의 관계 — 스타일 전환 결정 필요

| | KayKit(지금) | Quaternius 체계(제안) |
|---|---|---|
| 비율 | 치비(머리 큼) | 보통 비율 |
| 영웅 수 | 5종이 전부(파츠 교환으로 변주 가능하나 몸·얼굴 5개) | 체형 18 × 헤어 20 × 파츠 62 조합 |
| 적 | 해골 4종 | 몬스터 50 + 인간형 7 + 영웅 체계로 만든 적 |
| 애니메이션 | 모델마다 내장(76~95개) | 공용 1벌(250+), 모델은 메시만 → 용량 더 작음 |
| 던전 소품 | KayKit Dungeon(계속 써도 됨) | Quaternius Modular Dungeon 도 있음 |

제안: Quaternius 체계로 전환한다. 지금 영웅 4명(레온·브란·세라·카일)과 해골은 새 체계로 다시 만든다(이름·스킬은 유지). 두 스타일을 섞지 않는다. 던전 소품은 당장 KayKit 을 그대로 두고, 스타일 차이가 눈에 띄면 바꾼다.

### 2.4 런타임 조립

영웅 모델을 미리 합쳐 두지 않고, 게임 안에서 파츠를 조립한다.

- 로딩: 체형·헤어·파츠·무기 glb 를 개별로 받는다(쓰는 것만). 애니메이션 glb 1벌을 받는다.
- 조립: 체형 스켈레톤에 파츠 스킨 메시를 붙인다(같은 릭이라 본 이름이 같음). 무기는 손 본에 붙인다.
- 장비 교체: 투구 파츠를 바꾸면 머리 파츠만 교체. 뽑기·장착 화면에서도 같은 함수를 쓴다.
- 초상화: 지금처럼 조립된 모델을 카메라로 찍는다.
- 성능: 영웅 13k × 4 + 적 8마리 ≈ 15만 삼각형, 예산(30만) 안. 드로우콜은 파츠 수만큼 늘어나므로(영웅 1명 = 5~7 메시) 합치기(merge) 를 로딩 때 한다.

PoC 로 먼저 확인할 것(3-1 단계): Babylon 에서 (a) 파츠 메시가 체형 스켈레톤을 공유하는지, (b) UAL 애니메이션이 Base·Races·Bestiary 전부에 그대로 붙는지, (c) 폰에서 60fps.

## 3. 장비

### 3.1 부위와 보이는 방식

| 부위 | 보임 | 모델 출처 | 종류 수(v2) |
|---|---|---|---|
| 무기 | 손 | 아래 무기 팩 | 160 |
| 투구 | 머리 파츠 교체 | Outfits 머리 파츠 + KayKit 모자류 | 20 |
| 갑옷 | 몸통(+팔·다리) 파츠 교체 | Outfits 몸통 파츠 | 25 |
| 망토 | 등 | Outfits 망토 파츠 | 10 |
| 방패(보조) | 왼손 | 무기 팩 방패 | 15 |
| 장신구 2칸 | 안 보임 | 아이콘 | 60 |
| 문장(파티 효과) | 안 보임 | 아이콘 | 20 |

설계 문서의 "장신구 2칸 + 문장" 은 유지하고, "투구·갑옷" 을 보이는 부위로 올린다. 망토·방패는 새로 추가(보이는 부위가 많아야 장비 뽑기가 재미있다).

### 3.3 장비 아이템 정의

```
아이템 = 기본형(모델 + 부위 + 무기군) × 등급 × 주옵션 × 부옵션(0~4) × 고유 효과(전설 이상) × 세트
```

- 기본형은 모델 하나에 하나. 같은 모델이 여러 등급으로 나오되, 전설 이상은 "전용 기본형" 풀을 따로 둔다(엘리멘탈 무기, 특이한 실루엣). 같은 모델이 일반과 초월에 둘 다 나오지 않는다.
- 등급별 색·이펙트: 전설 이상은 무기에 글로우·파티클(기존 fx 로), 초월은 트레일.
- 무기군 호환: 영웅마다 쓸 수 있는 무기군 1~2개. 애니메이션은 무기군에 따라 고른다(UAL 에 검·도끼·활·지팡이·격투 동작이 있음).
- 고유 효과·세트는 design.md 4장 그대로.

## 4. 뽑기 (design.md 5장 구체화)

| 뽑기 | 재화 | 내용물 | 보장 |
|---|---|---|---|
| 영웅 소환 | 보석 150 / 10연 1,350 | 영웅 60명(등급 확률 design.md 3.3) | 10연 희귀+, 80회 전설+, 300회 신화+ |
| 픽업 소환 | 보석 | 주간 영웅 1명 확률 2배 | 천장 때 픽업 확정, 이월 |
| 장비 소환 | 장비 소환권(스테이지·일일 보상) 또는 골드 2,000 | 무기·투구·갑옷·망토·방패·장신구·문장 전부 | 10연 영웅+ 1개 |
| 무기 소환 | 골드 3,000 | 무기만 | 10연 영웅+ 1개 |

- 결제 없음. 모든 재화는 플레이로.
- 중복 영웅 → 조각(승급). 필요 없는 장비 → 분해(강화 재료·제작 재료).
- 연출: 소환진 → 카드 뒤집기(등급 색) → 전설 이상은 3D 모델이 등장해 포즈(UAL 감정 동작) → 10연 결과 격자. 스킵 가능.
- 뽑기 화면에 천장 카운터와 확률표(모바일 게임 관례).

## 5. 데이터와 도구

```
data/
├── quaternius/            원본 팩 (받은 그대로)
├── weapons/               무기 팩 원본
├── heroes.json            영웅 60명: id, 이름, 등급, 종족, 진영, 조합(체형·헤어·파츠·색), 무기군, 스킬 id, 능력치
├── items.json             기본형 목록: 모델, 부위, 무기군, 등급 풀
├── uniques.json           고유 효과·세트
└── skills.json            스킬·필살기 정의 (지금 data.ts 의 코드 부분은 효과 id 로 참조)
src/tools/
├── optimize-assets.mjs    (있음) 모델 압축
├── import-packs.mjs       팩별 다른 형식·텍스처를 공통 glb 로 정리 (재질 통일, 이름 규칙)
└── check-heroes.mjs       영웅 조합 중복·누락 검사 (같은 파츠 2개 이상 겹치면 실패)
```

스킬 효과는 코드(지금 data.ts 의 run 함수)로 남기되, 영웅은 JSON 에서 스킬 id 로 가리킨다. 60명의 스킬을 다 새로 쓰기보다 효과 20~30개를 매개변수(배율·대상·지속)로 조합한다.

## 7. 결정이 필요한 것

1. 스타일 전환: KayKit 치비 → Quaternius 보통 비율. 지금 영웅 4명·해골을 새 체계로 다시 만든다.
2. 유료 Source 구매 여부: Universal Base Characters $20, Modular Outfits $20 (각각 무료는 60~70%). 무료로 먼저 가고 조합이 모자라면 산다 / 처음부터 산다.
3. 장비 소환 재화: 소환권+골드(제안) / 보석(영웅과 공유).
4. 망토·방패 부위 추가(제안) / 설계 원안(무기·투구·갑옷·장신구 2·문장) 유지.
