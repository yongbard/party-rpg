# 설계 문서 — 파티 RPG (party_rpg_261116)

작성: 2026-11-16. 대화에서 정한 내용을 옮겨 적은 것. 바뀌면 이 문서를 고친다.

## 0. 한 줄 요약

모바일 세로 화면 웹에서 혼자 즐기는 3D 실시간 자동 전투 파티 RPG.
캐릭터는 뽑기로 모으고(8등급, 위로 갈수록 확률이 급감), 장비·특성 트리·행동 방침으로
같은 캐릭터를 다르게 쓸 수 있다. 전투는 자동으로 흐르고 플레이어는 필살기 탭으로 끼어든다.

## 1. 확정한 방향

- 솔플. 서버 없음. 저장은 기기 안(localStorage, 데이터가 작아서 IndexedDB 대신) + 내보내기·가져오기.
- 턴제 아님. 실시간 자동 전투 + 필살기 탭 + 배속.
- 로그라이트(갈림길·유물)는 쓰지 않는다. 스테이지 기반 RPG, 영구 성장 중심.
- 자유 스킬 슬롯은 없다. 캐릭터마다 스킬은 고정이고, 자유도는 파티 구성·특성 트리·장비·행동 방침에서 나온다.
- 캐릭터는 설계 의도(딜탱 유도형, 퓨어딜러 등)를 갖고 만들되, 플레이어가 꼭 그렇게 쓰지 않아도 되게 한다.
- 등급 8단계. 높은 등급은 확률이 아주 낮고 그만큼 효과가 좋다. 최대 성장치도 등급이 정한다.
- 불멸·초월 안전장치: 최상위 콘텐츠에서 조각이 느리게 떨어진다.
- 아트는 스타일라이즈드 3D. 모델·음악·UI는 오픈소스를 먼저 찾고, 없으면 만든다.
- 배포: 어디서든 폰으로 접속할 수 있게 공개 URL(GitHub Pages)에 올린다. 사용자가 늘어도 좋다.
- 기술: Babylon.js + TypeScript + Vite. WebGPU 우선, WebGL2 자동 대체.

## 2. 전투

- 파티 4명. 앞줄 2, 뒷줄 2. 전투 중 앞뒷줄 교체 가능.
- 실시간 자동. 일반공격과 스킬 2개는 쿨다운마다 자동 사용. 필살기는 게이지 100%일 때 초상화를 탭해 발동.
- 필살기 타입: 대상 지정형(탭 후 적 선택), 즉발형, 설치형(보호막·장판).
- 배속 1×/2×/3×, 일시정지.
- 필살기 때 카메라 컷인(짧은 클로즈업). 3D 퀄리티 체감의 핵심.
- 능력치: HP, 공격, 방어, 속도, 치명타, 회복력, 위협.
  - 데미지 = 공격 × 스킬 계수 − 방어 × 0.5 (하한 1)
  - 치유량 = 공격 × 스킬 계수 × 회복력 보정. 치유가 공격력 기반이라 딜러에게 치유 수단을 주면 실제로 힐이 된다.
  - 위협: 적은 위협이 높은 아군을 때린다. 특성·장비로 올리고 내린다. 탱커 장비를 낀 딜러가 실제로 맞는다.
- 행동 방침: 캐릭터마다 플레이어가 고른다. 공격 우선 / 생존 우선 / 아군 보호 / 약한 적부터.

## 3. 캐릭터

### 3.1 구성 (고정)

- 일반공격 1, 스킬 2(자동), 필살기 1, 패시브(등급별 0~3개). 자유 슬롯 없음.
- 진영 4개(왕국·숲·사막·심연, 이름은 바뀔 수 있음). 같은 진영 2명이면 소형, 3명 이상이면 대형 시너지.
- 설계 의도(원형)를 캐릭터마다 하나 정한다. 플레이어가 따르지 않아도 된다.

| 원형 | 설계 의도 | 다르게 쓰는 예 |
|---|---|---|
| 딜탱 유도형 | 위협 중간, HP·공격 균형, 피해를 받으면 강해지는 패시브 | 위협을 낮추는 특성을 찍고 뒷줄 딜러로 |
| 퓨어딜러 | 공격·치명 극단, HP 낮음 | 수호자의 면갑을 끼워 미끼 탱커로 |
| 딜힐 | 공격 기반 치유 스킬 1개 | 치유 특성을 버리고 순수 딜러로 |
| 순수힐 | 회복력 높음, 공격 낮음 | 역천의 지팡이로 딜힐로 |
| 서포터 | 버프·디버프·게이지 충전 | 공명의 문장과 함께 필살기 파티의 핵으로 |
| 광역형 | 다수 적에게 강함, 단일 약함 | 보스전에서는 쓰지 않는 선택도 가능 |

### 3.2 특성 트리 (캐릭터별 전용)

- 캐릭터마다 가지 3개. 가지 1은 설계 의도를 강화하고, 가지 2·3은 다른 쪽으로 끌어 간다.
  - 예: 딜탱 유도형 → 가지 1 수호(위협·피해 감소), 가지 2 격노(공격·치명), 가지 3 흡수(피해의 일부 치유)
- 특성 포인트는 등급과 별(승급)이 정한다. 포인트 초기화는 골드로 언제든.
- 가지 끝 노드는 규칙을 바꾸는 효과(예: 필살기가 아군 보호막으로 바뀜).

### 3.3 등급 8단계

| 등급 | 뽑기 확률 | 최대 레벨 | 능력치 배율 | 특성 포인트 | 고유 요소 |
|---|---|---|---|---|---|
| 일반 | 45% | 40 | 1.0 | 4 | — |
| 고급 | 30% | 50 | 1.15 | 5 | — |
| 희귀 | 16% | 60 | 1.35 | 6 | 패시브 1 |
| 영웅 | 6.5% | 70 | 1.6 | 8 | 패시브 1 |
| 전설 | 1.8% | 80 | 2.0 | 10 | 패시브 2 |
| 신화 | 0.5% | 90 | 2.5 | 12 | 패시브 2, 필살기 2단계 |
| 불멸 | 0.15% | 100 | 3.2 | 14 | 패시브 2, 필살기 2단계, 파티 오라 |
| 초월 | 0.05% | 120 | 4.0 | 16 | 패시브 3, 필살기 3단계, 파티 오라 |

- 승급: 같은 캐릭터 조각으로 등급 안에서 별 1~5. 별마다 최대 레벨 +5, 특성 포인트 +1.
- 등급 승격: 조각 + 승격석 대량으로 등급 1단계 상승(불멸까지, 초월은 승격 불가).
- 중복 뽑기는 조각으로 변환. 변환량은 등급별로 정한다(일반 10 … 초월 500 정도, 조정 예정).
- 수량: v1 16명(8등급 골고루, 진영당 4명) → 목표 40명.

## 4. 장비

| 항목 | 설계 |
|---|---|
| 부위 | 무기, 투구, 갑옷, 장신구 2칸, 문장(파티 단위 효과, 1개만 장착) |
| 등급 | 캐릭터와 같은 8단계. 등급이 주옵션 크기와 부옵션 수(0~4)를 정한다 |
| 전설 이상 | 고유 효과 1개. 수치가 아니라 규칙을 바꾼다 |
| 신화 이상 | 고유 효과 + 조건부 2차 효과 |
| 불멸·초월 | 고유 효과가 파티 전체에 걸린다 |
| 세트 | 2 / 4 세트. 4세트는 파티 운영 방식을 바꾸는 수준 |
| 강화 | +0 ~ +15, 실패 없음. +10, +15 에서 고유 효과 강화 |
| 획득 | 던전 드랍(주) + 제작(재료로 특정 전설 장비 확정) + 장비 뽑기(보조) |

고유 효과 예시

| 장비 | 등급 | 효과 | 바뀌는 역할 |
|---|---|---|---|
| 피의 서약 (무기) | 전설 | 가한 피해의 25%를 HP가 가장 낮은 아군에게 치유 | 딜러 → 딜힐 |
| 수호자의 면갑 (투구) | 전설 | 위협 2배, 받는 피해 −25%, 공격 −15% | 딜러 → 딜탱 |
| 역천의 지팡이 (무기) | 신화 | 치유할 때 치유량의 60%만큼 가장 가까운 적에게 피해 | 힐러 → 딜힐 |
| 고독한 검 (무기) | 신화 | 파티가 2명 이하이면 공격 +80%, 속도 +30% | 소수 정예 |
| 희생의 문장 (문장) | 불멸 | 아군이 쓰러지면 남은 아군 전원 공격 +25%, 중첩 | 소모전 파티 |
| 공명의 문장 (문장) | 초월 | 파티 전원의 필살기 게이지 공유. 누구든 탭하면 전원 필살기 | 파티 성격 자체 |

## 5. 뽑기와 재화

결제 없음. 보석은 전부 플레이로 번다.

| 종류 | 비용 | 내용 | 보장 |
|---|---|---|---|
| 상시 캐릭터 | 보석 150 / 10연 1,350 | 전체 캐릭터, 3.3 확률표 | 10연에 희귀 이상 1, 80회 천장 전설 이상, 300회 천장 신화 이상 |
| 픽업 캐릭터 | 동일 | 주간 로테이션 1명 확률 2배(같은 등급 안에서) | 천장 때 픽업 확정, 천장 카운트 이월 |
| 장비 뽑기 | 골드 2,000 / 10연 18,000 | 고급~신화 장비 | 10연에 영웅 이상 1 |
| 무료 뽑기 | 하루 1회 | 일반~영웅 | — |

- 불멸·초월은 천장 없음. 대신 무한탑 고층·레이드에서 조각이 느리게 떨어진다(안전장치).
- 연출: 카드 뒤집기, 등급별 빛 색, 전설 이상은 전조 연출. 스킵 버튼 필수.
- 뽑기 결과는 연출 전에 저장(새로고침으로 다시 뽑기 방지).

| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 골드 | 모든 전투, 판매 | 레벨, 강화, 장비 뽑기, 특성 초기화 |
| 보석 | 스테이지 별, 업적, 일일·주간 임무, 무한탑 기록 | 캐릭터 뽑기 |
| 캐릭터 조각 | 중복 뽑기, 조각 던전, 최상위 콘텐츠 | 승급, 등급 승격 |
| 승격석 | 요일 던전, 레이드 | 등급 승격 |
| 경험치 물약·스킬 책 | 요일 던전, 전투 | 레벨, 스킬 레벨 |
| 제작 재료 | 요일 던전, 분해 | 장비 제작 |

보석 수입 기준: 하루 평균 150(1회), 주간 합산 약 1,500. 이 숫자를 기준으로 균형을 잡는다.
스태미나는 두지 않는다. 요일 던전 하루 3회 제한만 둔다.

## 9. 기술

| 항목 | 선택 |
|---|---|
| 엔진 | Babylon.js (PBR, 애니메이션 블렌딩, 파티클, GUI, 후처리, glTF 내장) |
| 렌더링 | WebGPU 우선, WebGL2 자동 대체 |
| 그래픽 | PBR + HDRI, 그림자 1단, 블룸·톤매핑·SSAO, 필살기 컷인 |
| 성능 예산 | 캐릭터 1만~2만 삼각형, 화면 30만 이하, 텍스처 1024, 드로우콜 100 이하, 중급 폰 60fps |
| 코드 | TypeScript + Vite. 캐릭터·장비·스킬·적·특성은 JSON 테이블 |
| 저장 | localStorage(JSON), 내보내기·가져오기 |
| 배포 | GitHub Pages(정적) + PWA. 사용자가 늘어 계정·클라우드 저장이 필요해지면 그때 서버를 붙인다 |
